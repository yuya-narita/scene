# AUTO Timing Editor v1

Advanced Studio now exposes per-Scene AUTO timing.

- Shows recorded Scene.pause in seconds.
- Scene rail displays `AUTO x.xx s` when a timing is stored.
- Adjust with -0.5 / -0.1 / direct seconds / +0.1 / +0.5.
- Reset removes `scene.pause`, returning to Player default AUTO delay (2.60 s).
- Values remain stored as milliseconds in Scene Format.
