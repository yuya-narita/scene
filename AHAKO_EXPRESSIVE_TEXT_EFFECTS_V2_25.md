# AHAKO EXPRESSIVE TEXT EFFECTS V2.25

- Added four responsive manga balloon styles for normal Scenes:
  - Speech / 通常
  - Cloud / 雲
  - Burst / ギザギザ
  - Narration box / ナレーション枠
- Balloon width and height follow the rendered text, with a viewport-safe maximum width.
- Balloon styling stays on `.sp-text`, so existing entrance effects move the text and balloon together.
- Existing Chat view keeps its dedicated speaker bubble UI and takes precedence.
- Added `presentation.balloon.type` to Scene Format v1 schema.
- Added balloon selection to Advanced, desktop detail, desktop Live, and iPhone Live editing surfaces.
- Audio, ending audio assets, viewport handling, and public-player files are unchanged.
