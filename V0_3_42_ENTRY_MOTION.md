# v0.3.42 — Scene Entry Motion

- Added `presentation.entryMotion`: `flow` (existing Jump/Shino landing) / `still` (appear at final reading position).
- `entryMotion` is independent from `presentation.effect`, so `still + blur`, `still + fade`, `still + typewriter`, etc. are possible.
- Added Studio controls in Advanced Editor, Live Editor, and Effect Detail.
- Public Player and Studio Preview share the same behavior.
