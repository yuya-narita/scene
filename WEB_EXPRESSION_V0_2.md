# Web Expression v0.2 — Board UX

- Board metadata auto-fills: post number, anonymous name, current date/time, generated ID.
- Added email field for `sage` / `age`-style values.
- Added “Board mode from this Scene onward” bulk conversion with automatic sequential numbering.
- Board input fields stop keyboard events from leaking into Scene navigation.
- Player board design changed from card UI to a flatter old anonymous-board / past-log presentation.
- Synced public, Studio, local, and test Player cores.
