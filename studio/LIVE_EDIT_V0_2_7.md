# Live Edit v0.2.7

- Current Scene text tap now starts inline editing immediately and opens the iPhone keyboard.
- Aa is now text appearance: font, size, color, shadow.
- Added + to insert an empty Scene immediately after the current Scene and jump to it.
- Added Scene menu (…) with move previous, move next, duplicate, and delete.
- Scene operations reload Live Preview at the edited Scene instead of returning to Advanced.
- Mobile command strip is six equal keyboard-like keys.
