# Desktop Responsive v1 — v0.2.22

Responsive targets:
- 1024–1440px: Advanced workspace gets side margins and slightly denser sizing.
- 1441–1699px: balanced desktop baseline.
- 1700px+: Easy and Advanced both grow; typography increases slightly to approximate a comfortable 120% browser-zoom feel.
- 2200px+: growth is capped.

Design intent:
- Easy stays a readable writing column.
- Advanced uses more horizontal space as an editing desk.
- Existing mobile/tablet behavior is left intact.
