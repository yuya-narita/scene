# Live Edit v0.2.3

- Aa no longer opens a modal or duplicate textarea.
- Aa makes the currently visible Scene text directly editable in the Player.
- iPhone Safari uses the native keyboard while the original text remains in place.
- Player tap/keyboard navigation is suppressed only while editing that text.
- Edits sync to both the Studio document and the active playback clone.
- Visual editing chrome around the text was removed; the caret is the primary edit indicator.
