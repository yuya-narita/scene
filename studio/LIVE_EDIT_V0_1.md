# Live Edit v0.1

Preview-first authoring prototype.

- Every normal Studio Preview now enters Live Edit.
- Current Scene text can be tapped directly to edit.
- Bottom toolbar: Aa Text / ✦ Effect / ▣ Background / ♪ Audio.
- Effect sheet supports quick changes for entrance, display, text size and font.
- Background and Audio show Scene status and jump to the selected Scene in Advanced for detailed editing.
- Scene drum/history can browse all Scenes, including future Scenes, while Live Edit is active.
- AUTO REC remains available; Live Edit controls hide while recording.
- Desktop opens the Live Edit sheet beside a reduced preview.
- Returning from Preview still uses the existing Studio scroll-position restoration path.

This version intentionally does not replace the existing Advanced editor. It tests the navigation/editing feel before deeper controls are moved into Live Edit.
