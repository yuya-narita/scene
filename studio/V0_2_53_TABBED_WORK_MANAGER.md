# v0.2.53 — Tabbed work manager

The work manager now has three filters:
- 全て — every local work, one work per row
- 途中 — works that have not been published
- 公開 — works with a publication URL

Published works are not duplicated in the 全て view.
A published work remains one local work row and carries either:
- 公開中
- 変更あり

The iPhone single-scroll modal and background scroll lock from v0.2.52 are retained.
