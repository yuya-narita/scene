プライバシーポリシー

あ箱は、Scene作品を制作・配布・閲覧する仕組みと、Web文章をScene形式で読む「あ箱 Reader β」を提供します。

1. Readerが扱う情報

ユーザーが「あ箱で読む」を実行したページについて、本文、作品名・タイトル、作者情報、ページURLをReaderが一時的に扱う場合があります。これらは文章抽出、Scene化、表紙表示、作者版の確認などReaderの機能を提供するために使用します。

2. 本文の処理

本文のScene分割はブラウザ内で行います。本文、作品名、作者名を利用統計として外部サーバーへ送信することはありません。

Readerを開くために一時的に保存した本文データは、Readerが読み込んだ後にローカルの一時保存領域から削除します。

3. 通信ONの場合

初回利用時にネットワーク通信を使用するか選択できます。通信をONにした場合、以下の通信をHTTPSで行います。

  • 作者版の確認：現在の記事に作者が公開した「あ箱」版が存在するか照合するため、記事URLをあ箱のAPIへ送信します。
  • 匿名の利用統計：Readerのバージョン、読み込み方法、生成Scene数、Scene進行、読了、作者版の検出数、Reader内の導線利用などを送信する場合があります。

利用統計には、記事URL、ドメイン、URLパス、本文、作品名、作者名を含めません。

4. 通信OFFの場合

通信をOFFにしてもReaderの文章抽出・Scene化・閲覧機能は利用できます。作者版の自動確認と匿名利用統計の送信は停止します。設定はReader内の「DATA」から変更できます。

5. Distribution.sceneの匿名観測

配布用のDistribution.sceneを対応Playerで開いた場合、作品の閲覧状況を作者・運営者が把握するため、匿名の読書観測を行う場合があります。

作品ID、copyId、copyId専用の匿名observerId、sessionId、arrivalId、Scene数、現在位置、開始・進行・読了イベントを送信します。RELAY版ではrelayId、parentRelayId、hop、sourceArrivalIdも送信する場合があります。

氏名、メールアドレス、購入者情報、注文情報、アカウントID、ファイル名、保存場所、作品本文、作品タイトル、作者名は、この匿名観測データとして送信しません。

observerIdはcopyIdごとに生成し、異なるcopyId間の共通識別子として使用しません。同じ人物の複数端末・ブラウザ等を別の観測として含む場合があり、通信できない環境での閲覧は観測されません。

6. RELAY

RELAYでは、同じcopyIdを維持したまま新しいrelayIdを持つ配布データを生成します。つながりを表すため、作品ID、copyId、relayId、parentRelayId、hop、sourceArrivalIdをAPIへ送信する場合があります。

送信者・受取人の氏名、メールアドレス、アカウント、連絡先、購入者情報は記録しません。記録するのは、どの一冊がどの匿名の到達点から送り出され、次のPlayerで観測されたかという経路情報です。

7. 本棚とローカル設定

本棚のMaster、Distribution、copyId、表示設定、通信設定など、機能に必要な情報をブラウザ内の保存領域に保存する場合があります。作品本体をサーバーへ送信しない操作もあります。端末やブラウザのデータを削除すると失われる場合があります。

8. お問い合わせフォーム

お問い合わせフォームでは、返信先メールアドレス、任意のお名前、種類、件名、本文、送信元ページ、送信日時を取得します。これらはお問い合わせへの返信、内容の確認、不具合対応およびサービス運営のために利用します。

お問い合わせは管理者のみがアクセスできる受信箱に保存し、対応上必要な期間を超えて保有しないよう管理します。お問い合わせ情報を広告配信、行動ターゲティング、信用判断、データ販売に利用しません。

9. データの販売・広告利用

本サービスが扱うデータを販売・貸与したり、パーソナライズ広告、リターゲティング広告、信用判断、データブローカー用途に使用したりすることはありません。

10. 第三者への提供

機能提供に必要な場合、法令への対応が必要な場合、またはセキュリティ上必要な場合を除き、ユーザーデータを第三者へ販売または提供しません。

11. セキュリティ

あ箱のAPIへの通信にはHTTPSを使用します。管理画面のお問い合わせ受信箱には管理者認証を設けます。ただし、インターネット上の通信・保存に関する完全な安全性を保証するものではありません。

12. Chrome Web Store Limited Use

あ箱 Reader βによるユーザーデータの利用は、Chrome Web Store User Data Policy（Limited Use要件を含む）に従います。取得した情報は、Readerの単一目的である「Web文章をScene形式で読む体験の提供」と、それに必要な機能・運用のためにのみ使用します。

13. ポリシーの変更

データの取扱いを変更する場合は本ページを更新し、必要に応じて本サービス内またはChrome Web Store上で利用者に分かる形で告知します。
