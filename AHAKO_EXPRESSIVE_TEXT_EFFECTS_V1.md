# A-Hako Expressive Text Effects v1

Added four one-shot text entrance effects for music / lyric works:

- `slam` — text is struck down into the screen
- `burst` — text bursts outward with overshoot
- `glitchHit` — short stepped digital impact
- `rush` — text rushes in horizontally

Updated Studio selectors (mobile / desktop / advanced), Japanese/English labels, Scene Format v1 schema, and all three Core CSS copies (root / studio / player-test).

This patch does **not** change Splitter, Admin, Privacy, Chat, Scene image, audio, AUTO REC, or resonance calculation. Resonance-driven effect intensity is intentionally left for the next layer after these base effects are visually tested.
